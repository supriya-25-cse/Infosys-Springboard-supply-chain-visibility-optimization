# Infosys Springboard – Supply Chain Visibility and Optimization

Infosys Springboard Virtual Internship 7.0 — Data Visualization Project.

## 📌 Project Overview

This project focuses on analyzing supply chain data to improve visibility, understand operational performance, and support data-driven decision making.

The project covers data preprocessing, exploratory data analysis, dashboard development, and final supply chain analysis using Python and Power BI.

## 🎯 Project Objectives

- Analyze supply chain data and identify important patterns.
- Clean and preprocess the dataset.
- Perform Exploratory Data Analysis (EDA).
- Analyze inventory, product movement, transportation, quality, revenue, and sales.
- Develop interactive Power BI dashboards.
- Generate meaningful insights and recommendations.

## 🛠️ Tools and Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Power BI
- Jupyter Notebook / Google Colab
- GitHub
